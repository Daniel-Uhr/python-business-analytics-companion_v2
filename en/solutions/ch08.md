## The fuel-station chain

For 80 stations the chain records daily liters sold, own price per liter, the nearest competitor’s price and traffic in thousands of vehicles per day. The laboratory has homoskedastic disturbances. Run the setup before analyzing the stations.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf
from scipy import stats

rng = np.random.default_rng(2026)
n_postos = 80
postos = pd.DataFrame({"price": np.round(rng.uniform(5.5, 6.5, size=n_postos), 2)})
postos["competitor_price"] = np.round(postos["price"] + rng.normal(0, 0.15, size=n_postos), 2)
postos["traffic_thousands"] = np.round(rng.uniform(5, 25, size=n_postos), 1)
postos["liters"] = np.round(
    9_000 - 2_500 * postos["price"] + 1_800 * postos["competitor_price"] + 300 * postos["traffic_thousands"]
    + rng.normal(0, 600, size=n_postos)
)
```

## Solution to Exercise 01 — Fit the demand equation

Regress liters on own price, competitor price and road traffic. Interpret the own-price slope and express it for a ten-cent increase.

At fixed competing price and traffic, a one-dollar higher price per liter is associated with 3,097 fewer liters sold per day. A ten-cent difference corresponds to about 310 fewer liters daily.

```python
model = smf.ols("liters ~ price + competitor_price + traffic_thousands", data=postos).fit()
```

## Solution to Exercise 02 — Reconstruct the standard error and test

Estimate the disturbance standard deviation, degrees of freedom, conventional slope standard error, t statistic and two-sided p-value for a zero price slope. Check the software outputs.

The residual standard deviation is 650.2 liters, with 76 degrees of freedom. Dividing it by the square root of the residualized price sum of squares gives 556.2. The t statistic is −5.57 and the two-sided p-value is about 0.000000372.

```python
gl = len(postos) - 3 - 1
sigma_chapeu = np.sqrt((model.resid ** 2).sum() / gl)
change_propria = smf.ols("price ~ competitor_price + traffic_thousands", data=postos).fit().resid
erro_padrao = sigma_chapeu / np.sqrt((change_propria ** 2).sum())

t_zero = model.params["price"] / erro_padrao
p_zero = 2 * (1 - stats.t.cdf(abs(t_zero), df=gl))
print(f"σ̂ = {sigma_chapeu:.1f} liters; degrees of freedom = {gl}")
print(f"SE by hand = {erro_padrao:.1f}; statsmodels = {model.bse['price']:.1f}")
print(f"t = {t_zero:.2f} (statsmodels {model.tvalues['price']:.2f}); p-value = {p_zero:.2e} (statsmodels {model.pvalues['price']:.2e})")
```

```text
σ̂ = 650.2 liters; degrees of freedom = 76
SE by hand = 556.2; statsmodels = 556.2
t = -5.57 (statsmodels -5.57); p-value = 3.72e-07 (statsmodels 3.72e-07)
```

## The contact center

The center records in-person and online training hours during the semester, years of experience and cases resolved per day for 150 agents. Agents who take more hours in one format often take more in the other. The simulated data have constant error variance.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf
from scipy import stats

rng = np.random.default_rng(2026)
n_atendentes = 150
equipe = pd.DataFrame({"experience_years": np.round(rng.uniform(0, 10, size=n_atendentes), 1)})
equipe["in_person_h"] = np.round(np.clip(25 - 2 * equipe["experience_years"] + rng.normal(0, 4, size=n_atendentes), 0, None), 1)
equipe["online_h"] = np.round(np.clip(0.6 * equipe["in_person_h"] + rng.normal(0, 1.5, size=n_atendentes), 0, None), 1)
equipe["productivity"] = np.round(
    10 + 0.12 * equipe["in_person_h"] + 0.12 * equipe["online_h"] + 1.2 * equipe["experience_years"]
    + rng.normal(0, 2, size=n_atendentes), 1
)
```

## Solution to Exercise 07 — Test the formats separately

Regress productivity on both training-hour measures and experience. Give each format’s coefficient, standard error and p-value. What conclusion might be premature?

In-person hours give 0.088 daily cases per hour, SE 0.081, p = 0.281. Online hours give 0.172, SE 0.115, p = 0.139. Neither individual test rejects zero at 5%. The two results do not test the joint contribution of training.

## Parrot Cellars

For 200 wines the retailer randomly changes bottle prices by −10, zero or +10 dollars for one month. Quality and baseline prices are recorded before assignment. Management will raise prices only if a ten-dollar increase costs fewer than 50 monthly sales per wine.

Interpretation conditions: one assignment per wine, complete outcomes, implementation of the assigned price, and no spillovers across wines. Random assignment balances prior characteristics over repetitions, not exactly in each sample. Controls are selected before inspecting outcomes; the linear-response specification and conventional standard errors still require their own assumptions. The 50-bottle threshold is supplied, not estimated from costs.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_rotulos = 200
vinhos = pd.DataFrame({"quality": np.round(rng.uniform(70, 95, size=n_rotulos), 1)})
vinhos["base_price"] = np.round(np.clip(-240 + 4 * vinhos["quality"] + rng.normal(0, 12, size=n_rotulos), 20, None), 2)
vinhos["change"] = rng.choice([-10, 0, 10], size=n_rotulos)
vinhos["price"] = vinhos["base_price"] + vinhos["change"]
vinhos["sales"] = np.round(-1_900 - 6 * vinhos["price"] + 35 * vinhos["quality"] + rng.normal(0, 40, size=n_rotulos)).astype(int)
```

### Transfer within Exercise 18 — Sensitivity and decision

Use the adjusted model and transform the coefficient interval into a bottle-loss interval for a USD 10 increase. Verify compliance, no interference, and outcome completeness before a causal operational conclusion.
