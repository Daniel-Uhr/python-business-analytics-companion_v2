# Exercises and Worked Solutions

Supplementary materials for **Python para Business Analytics: Estatística e Econometria** (Portuguese edition) and **Python for Business Analytics: Statistics and Econometrics** (English edition), Volume 2, by Daniel de Abreu Pereira Uhr.

## Choose your language

- **Português:** [exercícios e resoluções por capítulo](pt-br/README.md)
- **English:** [exercises and worked solutions by chapter](en/README.md)

## What this repository contains

This repository provides only exercise statements, worked solutions, student notebooks, and the data, figures, and instructions needed for the activities. The 17 teaching chapters, their explained examples, and the teaching companion notebooks are reserved for the books and are not distributed here.

Chapters 1–16 contain 289 exercises and their worked solutions in each language. Chapter 17 provides a final project with instructions, a data dictionary, an assessment rubric, a student template, and a separate worked solution.

## How to use these materials

Read the exercises, record your own attempt, and then consult the worked solutions. Download the entire package to preserve the folder structure of the data. Run each student notebook from its language folder; the Python code shown in the worked solutions uses the same working directory. Environment instructions are included in each language folder.

Fictional business scenarios are localized for each edition: the Portuguese materials use Brazilian reais, and the English materials use U.S. dollars. Both editions use the same real datasets: historical household data from Belgium, the U.S. RAND Health Insurance Experiment, and historical U.S. macroeconomic data. Their results are specific to the populations and periods represented. Fictional scenarios do not represent actual businesses.
