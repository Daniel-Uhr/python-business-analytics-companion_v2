A gestão só aumentará os preços se uma alta de R\$ 10 reduzir as vendas em **menos de 50 garrafas por mês** por rótulo.

Execute a célula abaixo antes de começar.

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_rotulos = 200
vinhos = pd.DataFrame({"qualidade": np.round(rng.uniform(70, 95, size=n_rotulos), 1)})
vinhos["preco_base"] = np.round(np.clip(-240 + 4 * vinhos["qualidade"] + rng.normal(0, 12, size=n_rotulos), 20, None), 2)
vinhos["variacao"] = rng.choice([-10, 0, 10], size=n_rotulos)
vinhos["preco"] = vinhos["preco_base"] + vinhos["variacao"]
vinhos["vendas"] = np.round(-1_900 - 6 * vinhos["preco"] + 35 * vinhos["qualidade"] + rng.normal(0, 40, size=n_rotulos)).astype(int)
```
