## Contexto — Marketplace

A marketplace, marketplace fictício, acompanha as **devoluções** de 400 vendedores em um mês. Os vendedores têm volumes muito diferentes: a exposição é o número de **pedidos** (em centenas). Também se registra se o vendedor tem o **selo** de qualidade da plataforma, concedido com base no seu histórico, e se vende na categoria **moda**, que tem mais trocas. Os vendedores diferem em muitas características que a plataforma não observa.

Os dados vêm de um laboratório, com o mecanismo escrito na célula abaixo. Execute-a antes de começar.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_vendedores = 400
vendedores = pd.DataFrame({
    "selo": rng.binomial(1, 0.4, size=n_vendedores),
    "moda": rng.binomial(1, 0.3, size=n_vendedores),
    "pedidos_cem": np.round(rng.uniform(0.5, 5, size=n_vendedores), 1),
})
heterogeneidade = rng.gamma(0.8, 1 / 0.8, size=n_vendedores)
taxa_lab = np.exp(np.log(2) - 0.3 * vendedores["selo"] + 0.6 * vendedores["moda"])
vendedores["devolucoes"] = rng.poisson(vendedores["pedidos_cem"] * taxa_lab * heterogeneidade)
```
