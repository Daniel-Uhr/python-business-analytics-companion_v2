## Contexto — Rede Beija-flor e as reclamações

No capítulo 5, um gerente da Beija-flor notou que lojas com mais reclamações tinham receita maior, e vimos que o **fluxo de clientes** explicava as duas coisas. Agora, outro gerente afirma: “as lojas grandes atendem pior — elas recebem muito mais reclamações”.

A célula abaixo reproduz as 80 lojas dos capítulos 5 e 7, com o mesmo código e a mesma seed. Note, no código, como as reclamações foram geradas: um sorteio de Poisson com média igual a 2 vezes o fluxo de clientes (em mil clientes no mês).

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_lojas = 80

area = rng.uniform(1, 4, size=n_lojas)
fluxo = 5 * area + rng.normal(0, 1.5, size=n_lojas)

lojas = pd.DataFrame({
    "area_mil_m2": area.round(2),
    "funcionarios": np.round(8 + 9 * area + rng.normal(0, 3, size=n_lojas)).astype(int),
    "fluxo_mil_clientes": fluxo.round(1),
    "reclamacoes": rng.poisson(2 * fluxo),
    "receita_mil": np.round(60 + 12 * fluxo + rng.normal(0, 25, size=n_lojas), 1),
})
```

## Resolução do Exercício 03 — Com exposição

**Raciocínio:** com o fluxo como exposição, o modelo descreve a taxa de reclamações por mil clientes.

## Contexto — Marketplace

A marketplace, marketplace fictício, acompanha as **devoluções** de 400 vendedores em um mês. Os vendedores têm volumes muito diferentes: a exposição é o número de **pedidos** (em centenas). Também se registra se o vendedor tem o **selo** de qualidade da plataforma, concedido com base no seu histórico, e se vende na categoria **moda**, que tem mais trocas. Os vendedores diferem em muitas características que a plataforma não observa.

Os dados vêm de um laboratório, com o mecanismo escrito na célula abaixo. Execute-a antes de começar.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_vendedores = 400
vendedores = pd.DataFrame({
    "selo": rng.binomial(1, 0.4, size=n_vendedores),
    "moda": rng.binomial(1, 0.3, size=n_vendedores),
    "pedidos_cem": np.round(rng.uniform(0.5, 5, size=n_vendedores), 1),
})
heterogeneidade = rng.gamma(0.8, 1 / 0.8, size=n_vendedores)
taxa_lab = np.exp(np.log(2) - 0.3 * vendedores["selo"] + 0.6 * vendedores["moda"])
vendedores["devolucoes"] = rng.poisson(vendedores["pedidos_cem"] * taxa_lab * heterogeneidade)
```

## Contexto — Operadora de saúde: quantas consultas a menos?

No capítulo 13, a operadora de saúde estimou, com o experimento da RAND, que uma coparticipação de 25% reduz a probabilidade de o segurado consultar um médico no ano em cerca de 9 pontos percentuais. Para os custos, importa o **número** de consultas.

A base e sua ficha estão em `data/ch14/`. Cada linha é uma pessoa em um ano; `mdvis` é o número de consultas ambulatoriais no ano. Como no capítulo 13, usamos os planos sem franquia individual, com coparticipação de 0%, 25%, 50% e 95%, e os controles de saúde `physlm`, `disea`, `hlthg`, `hlthf` e `hlthp`. Como todas as linhas correspondem a um ano, a exposição é a mesma para todas e não precisa entrar no modelo.
