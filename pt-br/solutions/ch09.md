## Contexto — Plataforma de vagas plataforma de vagas

A plataforma fictícia de vagas de emprego quer descrever como o **salário mensal oferecido** (R\$) varia entre **setores** — comércio, indústria, serviços e tecnologia —, considerando a **experiência exigida** (anos) e se a vaga é de **trabalho remoto** (1) ou não (0). Ela reuniu 400 vagas anunciadas. Os dados são didáticos.

Execute a célula abaixo antes de começar.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_vagas = 400
vagas = pd.DataFrame({"setor": rng.choice(["comércio", "indústria", "serviços", "tecnologia"], size=n_vagas, p=[0.3, 0.25, 0.3, 0.15])})
vagas["experiencia_anos"] = np.round(rng.uniform(0, 10, size=n_vagas), 1)
vagas["remoto"] = (rng.random(n_vagas) < 0.25).astype(int)
adicional_setor = vagas["setor"].map({"comércio": 0, "indústria": 400, "serviços": 200, "tecnologia": 2_500})
vagas["salario"] = np.round(2_000 + adicional_setor + 250 * vagas["experiencia_anos"] + 300 * vagas["remoto"]
                            + rng.normal(0, 500, size=n_vagas), -1)
```

## Contexto — Rede de calçados, retorno da mídia digital

A rede de calçados, rede de calçados do Capítulo 8, fez uma nova coleta em 300 lojas: **vendas** mensais (R\$ mil), investimento em **mídia digital** (R\$ mil), se a loja fica em **shopping** (1) ou na rua (0) e a **renda** média do bairro (R\$ mil). A diretoria suspeita que o retorno da mídia digital seja maior nos shoppings e nos bairros de renda mais alta. No Capítulo 8, vimos que, com margem de 40%, cada R\$ 1 mil em mídia precisa estar associado a pelo menos R\$ 2,5 mil em vendas para se pagar. Os dados são didáticos e homocedásticos.

Execute a célula abaixo antes de começar.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
n_lojas = 300
lojas = pd.DataFrame({"shopping": (rng.random(n_lojas) < 0.4).astype(int)})
lojas["digital"] = np.round(rng.uniform(2, 20, size=n_lojas), 2)
lojas["renda_mil"] = np.round(rng.uniform(1.5, 6, size=n_lojas), 2)
```

## Contexto — Rede de farmácias

A rede fictícia de farmácias tem 60 lojas em cada uma de quatro regiões (Sul, Sudeste, Nordeste e Norte). Para avaliar um cupom de desconto, ela **sorteou**, dentro de cada região, 30 lojas para oferecê-lo durante um mês. A tabela registra a região, a área de vendas (m²), se a loja ofereceu o cupom (1) ou não (0) e as vendas do mês (R\$ mil).

O cupom custa à rede cerca de **R\$ 4 mil por loja** no mês e a gestão fixou uma meta de vendas adicionais desse mesmo valor. Os dados são didáticos.

Execute a célula abaixo antes de começar.

```python
import numpy as np
import pandas as pd
import statsmodels.formula.api as smf

rng = np.random.default_rng(2026)
regioes = ["Sul", "Sudeste", "Nordeste", "Norte"]
drogarias = pd.DataFrame({"regiao": np.repeat(regioes, 60)})
drogarias["area_m2"] = np.round(rng.uniform(150, 400, size=240))
drogarias["cupom"] = np.concatenate([rng.permutation(np.repeat([0, 1], 30)) for _ in regioes])
nivel_regiao = drogarias["regiao"].map({"Sul": 80, "Sudeste": 95, "Nordeste": 70, "Norte": 65})
efeito_cupom = drogarias["regiao"].map({"Sul": 4, "Sudeste": 6, "Nordeste": 10, "Norte": 2})
drogarias["vendas"] = np.round(nivel_regiao + 0.1 * drogarias["area_m2"] + efeito_cupom * drogarias["cupom"]
                               + rng.normal(0, 6, size=240), 1)
```

## Resolução do Exercício 17 — Causal ou descritivo?

**Resposta:** dentro de cada região, o cupom foi **sorteado**: lojas com e sem cupom diferem, em média, apenas pelo cupom. Por isso, a diferença de vendas estima o efeito do cupom naquela região. Já as regiões não foram sorteadas: diferem em renda, concorrência, clima e perfil de clientes. As diferenças de nível de vendas entre regiões — e mesmo as razões pelas quais o efeito do cupom varia entre elas — são descritivas: sabemos **que** o efeito difere, não **por que**.
